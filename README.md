# Cooking Class with Dar Mohamed

A responsive trilingual website starter (English / French / Arabic) for the cooking experience in Fes.

## Included
- `index.html`, `style.css`, `script.js`
- Original photos supplied in the conversation, copied into `images/`
- WhatsApp booking link: https://wa.me/212639384644
- Flexible class duration; price set personally by Mohamed based on duration
- Optional traditional market visit
- No fixed prices published

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new public repository named `cooking-class-dar-mohamed`.
2. Upload all files and the `images` folder (keep the folder structure).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. GitHub will show the public website address in the Pages section.

This is a starter build, not yet published online. Add more real photos/videos later by placing them in `images/` and updating the gallery.
